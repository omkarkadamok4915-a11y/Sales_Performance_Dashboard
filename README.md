# Sales Performance Dashboard

This project is a Sales Performance Dashboard built in Power BI. It includes KPIs, sales trends, region-wise and product-wise analysis, and interactive slicers.

Tools Used:Power BI, DAX, Excel  

Dashboard Highlights:
- Total Sales, Profit, Quantity, Profit Margin KPIs
- Monthly Sales Trend Line Chart
- Region-wise and Product-wise analysis
- Interactive Slicers for Year, Month, Category, Region
